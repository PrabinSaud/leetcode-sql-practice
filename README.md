# LeetCode SQL Practice

A structured collection of my SQL solutions and practice problems from [LeetCode](https://leetcode.com/problemset/database/).

The goal of this repository is to strengthen my SQL skills through consistent problem-solving, while building a reference of SQL patterns commonly used in data analyst and SQL interview roles.

---

## 🎯 Objectives

- Strengthen SQL fundamentals
- Improve problem-solving and logical thinking
- Practice writing clean and readable SQL queries
- Understand common SQL interview patterns
- Practice MySQL syntax and functions
- Build a consistent SQL problem-solving habit
- Maintain a public record of my SQL learning progress

---

## 🛠️ SQL Dialect

**Primary Database:** MySQL

The solutions in this repository are written primarily using MySQL syntax.

---

## 📚 Topics Covered

As I progress through LeetCode problems, this repository will cover:

- `SELECT` and `WHERE`
- Filtering and conditional logic
- `AND`, `OR`, and `NOT`
- `ORDER BY`
- `GROUP BY`
- Aggregate Functions
  - `COUNT()`
  - `SUM()`
  - `AVG()`
  - `MIN()`
  - `MAX()`
- `HAVING`
- `JOIN`
  - `INNER JOIN`
  - `LEFT JOIN`
  - `RIGHT JOIN`
  - `SELF JOIN`
- Subqueries
- Common Table Expressions (`CTE`)
- `CASE` expressions
- Date and Time Functions
- String Functions
- Window Functions
  - `ROW_NUMBER()`
  - `RANK()`
  - `DENSE_RANK()`
  - `LAG()`
  - `LEAD()`
- Conditional Aggregation
- Set Operations
- NULL handling
- Advanced SQL problem-solving patterns
